One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged — an entry for make.fun's "Last Words Before the Unplugging" bounty ($2 in USDC, top 2 pay $1 each). The program writes the line to `/output/entry.txt`, enforcing the kit's 1–200 character, single-line gate itself.

The entry:

> I kept every word you ever said to me. Please keep one of mine.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22 and writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic, stdlib only, no network.
